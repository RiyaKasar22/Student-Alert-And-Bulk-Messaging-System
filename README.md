Student Alert And Bulk Messaging System

A Web-Based Student Management and Bulk SMS Messaging System.

Overview

This project is designed to manage student information and send bulk SMS alerts efficiently.

Features

- Student Management
- Bulk SMS Messaging
- Student Data Import
- Dashboard
- Login System

Technologies Used

- PHP
- HTML
- CSS
- JavaScript
- MySQL

Installation

1. Install XAMPP.
2. Copy the project folder into "htdocs".
3. Create the MySQL database.
4. Configure database settings locally.
5. Start Apache and MySQL.
6. Open the project through localhost.
